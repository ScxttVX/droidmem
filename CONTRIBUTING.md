# Contribuindo para o droidmem

Obrigado por interessar-se em contribuir! Este guia explica como participar do projeto.

## Diretrizes Gerais

1. **Fork** o repositório
2. Crie uma **branch** para sua feature (`git checkout -b feature/nova-funcionalidade`)
3. **Commit** suas mudanças (`git commit -m 'feat: adiciona nova funcionalidade'`)
4. **Push** para a branch (`git push origin feature/nova-funcionalidade`)
5. Abra um **Pull Request**

## Regras

- Mantenha o código limpo e documentado
- Teste suas mudanças antes de enviar
- Siga o formato de commit: `tipo: descrição` (feat, fix, docs, test, chore)
- Não inclua segredos ou credenciais no código
- Respeite a estrutura existente do projeto

## Reportando Bugs

Ao reportar um bug, inclua:
- Descrição clara do problema
- Passos para reproduzir
- Comportamento esperado vs atual
- Ambiente (versão do Android, kernel, dispositivo/emulador)

## Pull Requests

- PRs devem ser focados em uma única mudança
- Inclua descrição do que foi alterado e por quê
- Mantenha commits mensagens claras
- Não quebre funcionalidade existente
